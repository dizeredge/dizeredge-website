Release notes & checksums

Version 0.2.0 · Development preview · November 11, 2026

Included in this milestone

  • Windows/Android shared local TCP transfer protocol and native Bluetooth Classic RFCOMM adapters.
  • UDP LAN discovery, manual IPv4, persistent identities, explicit full-fingerprint pairing and pinned trust.
  • Receiver approval, bounded streaming, progress, cancellation, SHA-256 and safe new-folder commit.
  • Windows file/folder sending; Android individual-file sending, receiving and explicit folder export.
  • Per-user self-contained Windows setup and a development-signed Android APK.

See the machine-readable release manifest and package-specific SHA-256 files on each download page. Hashes detect changed bytes; verify their source as well. Windows is unsigned; Android uses a development certificate.

Known limitations

No pause/resume, durable interrupted-transfer recovery/history, empty-directory-only transfer, Android source-folder selection, individual named trust UI or automatic identity rotation. Android approval requires foreground UI; service duration is OS-limited. Physical interop, production signing and independent review remain release gates.

Version 0.1.0 was a foundation milestone with no active interoperable transfer listener. Use matching 0.2.0 versions on both endpoints. Cloud, internet transfer, accounts, subscriptions, macOS and iOS are outside this release.
