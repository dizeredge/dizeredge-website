Your first transfer

Two nearby devices. One approved transfer. Start with local Wi-Fi, then try Bluetooth if your devices support it.

Version 0.2.0 is a development preview. Physical Windows–Android Wi-Fi and Bluetooth interoperability has not yet been validated. Use copies of noncritical files for evaluation.

1. Get both devices ready

Install the same version on both devices. Windows requires Windows 10 build 19041 or later, or Windows 11, on x64 hardware. Android requires Android 8.0 or later on ARM64 or x86-64 hardware.

Connect to the same local Wi-Fi network, or connect Windows through Ethernet to that network. Internet access is unnecessary for transfers. You need network access to obtain the installers from this website.

2. Find the receiver

Open the app on both devices. Windows starts LAN receiving when opened; on Android, tap Start receiving. Keep both apps visible. Open Nearby devices and select the receiver. If discovery is blocked, enter its local IPv4 address on Send files.

3. Verify who you are connecting to

On both devices, select Allow pairing for 2 minutes, then select the target and choose Pair device. On each confirmation screen, compare every fingerprint group with the identity shown in Settings on the other physical device. Confirm only an exact match. A familiar device name is not proof of identity.

4. Send and approve

Select files, choose the paired target and start sending. Windows can also select a folder. The receiver must approve the file offer. Keep both apps visible for approval. The app streams the files and checks SHA-256 before marking the receive complete.

5. Find your received files

Windows creates a fresh Received-… folder in its configured download directory. On Android, verified files first go into private app storage. Open Receive files → Save latest received files to folder to export through the system folder picker. Export wanted files before uninstalling Android.

Continue with the Windows guide, Android guide or Bluetooth setup.
