Documentation/Applications

Windows app

A native desktop application for Windows 10 and Windows 11, with file and folder selection and local-network discovery.

Install and update

  1. Download the Windows x64 setup and compare its SHA-256 with the release details.
  2. Run setup, choose the per-user installation location and optionally create a desktop shortcut. The .NET runtime is included.
  3. Open DizerEdge - Secure File Sharing. Permit the app on the intended Private network if Windows Firewall prompts you.
This preview's application and installer are unsigned. Windows may display an unknown-publisher warning. Verify the source and checksum; if you cannot establish trust, cancel installation. Do not disable Windows security controls.

Close the application before updating. Use the same installer identity for updates. Upgrade/locked-file and clean-VM testing remain release gates; back up wanted files before evaluating an update.

Send files or folders

Open Send files. Add files, select a folder or drag files into the app. Review the selection and total size. Choose a nearby LAN/Bluetooth device, or enter a local IPv4 address for LAN. Pair and compare full fingerprints before sending to a new device. The receiving device must approve every offer.

Files inside selected folders preserve their relative structure. Empty files are supported; empty-directory-only transfers are not. Existing destination files are not overwritten: every receive creates a new transfer folder.

Receive and locate files

LAN receiving starts when the application opens. Review the sender, names and sizes in the incoming prompt before accepting. Change the default download directory in Settings before starting a transfer. Open the last verified destination folder after completion. Never run an unexpected received executable.

Devices and settings

Nearby devices lists discovered LAN devices; enable and refresh Bluetooth separately. Device names can be changed in Settings. Theme and download directory are configurable. The identity fingerprint is shown in Settings. Forget paired devices clears all pinned peers and cancels active protocol sessions; named individual removal is not available yet.

Progress, cancellation and history

Transfers show byte counts, speed, estimated time and encryption status. Cancel stops active work. Retry starts a fresh transfer; there is no pause/resume or automatic interrupted-transfer recovery. History is session-only. If the final acknowledgement is lost, check the receiver for a verified folder before retrying.

Uninstall and compatibility

Use Windows Settings → Apps to uninstall. The installer requires no administrator privileges or broad firewall exceptions. The delivered build is x64; a native ARM64 package has not been validated. Bluetooth requires a compatible Classic/RFCOMM adapter, driver and Windows permissions.

For network and hardware issues, see Troubleshooting. For test evidence, see Release notes.
